# S3a — GEOINT agent on a shared agent runtime: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second specialist agent (GEOINT) runs alongside SIGINT on every investigation. Both agents are built on one shared agent runtime, which also gains agent-side cancel. This closes AC3 and AC4 (GEOINT half).

**Architecture:**
- **Shared runtime.** SIGINT's generic plumbing moves into `nexus_shared.agent`: the SQLite task store, the Context Service client, the manifest catalog, the runner, the task API and the app factory.
- **Plug-ins.** Each agent package provides only an `AgentSpec`: its id, task types, `validate_request`, `run` pipeline and card text.
- **GEOINT itself.** A deterministic detector (co-location and conflict over grid cells), one OpenAI call per task to label the candidates, and `PLACED_AT` findings committed through the existing `findings:batch`.
- **Orchestrator.** Only configuration changes in S3a.

**Tech Stack:** Python 3.12, uv workspace, FastAPI, aiosqlite, httpx, Pydantic v2, OpenTelemetry, pytest + pytest-asyncio, Docker Compose.

**Spec:** `specs/02-features/S3-geoint-failure-paths.md` (approved 2026-11-25). Builds on `specs/02-features/S2-sigint-agent.md` §20. S3b (failure paths: FR-120–129, chaos, cancel UI) is a **separate plan** written after this one ships.

## Global Constraints

- Python `>=3.12`; ruff line length 100; `uv sync --all-packages --locked` must stay green, so update `uv.lock` when a pyproject changes.
- Model snapshot `gpt-5.4-mini-2026-03-17` (`OPENAI_MODEL_EXTRACT`). No new model.
- Confidence bands: LOW < 0.40 ≤ MODERATE < 0.75 ≤ HIGH.
- Only the orchestrator token may call agent `/v1/tasks*` endpoints.
- **Stored evidence summaries come from structured fields only.** Fixture `summary` text never reaches the graph (S2 §20 N11). Fixture summaries go to the LLM only inside the `<<<UNTRUSTED_EVIDENCE … UNTRUSTED_EVIDENCE>>>` fence.
- **Graph facts come from the detector only.** The LLM chooses label, confidence, statement and reasoning; it never changes `about`, evidence, assertions or windows.
- The replay key material must not change for SIGINT. The S2 recordings in `data/replay/sigint-agent/{baseline-corroboration,prompt-injection}` must still hit.
- `geoint-agent` mounts only `data/fixtures/geoint` and `data/replay/geoint-agent` (AC5).
- Never print or commit `OPENAI_API_KEY` or `.env`. Commits use Conventional Commits and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Analysis stays disabled: a run where both specialists succeed ends `PARTIAL(agent_not_enabled)` with `skipped_agents=[analysis-agent]`.

## Review Focus

1. **A GEOINT sighting whose subject is a HANDLE, LOCATION or unknown alias.** It must be dropped from detection and counted, never placed. Only PERSON and ASSET are placeable. Test owner: Task 6.
2. **A point exactly on a cell boundary or outside the grid.** Boundaries belong to the higher cell (`floor`). Off-grid points are dropped and counted. Test owner: Task 6.
3. **Touching windows** (A ends 10:00, B starts 10:00). These are half-open windows, so this is **not** an overlap. Test owner: Task 6.
4. **A refactored runtime that silently changes the SIGINT replay key or request hash.** S2 recordings would miss in production replay. Test owner: Task 3 (replay-hit test on the committed recordings).
5. **Cancel arriving while the commit is in flight.** The commit must not be interrupted. If the Context Service then answers 409 `investigation_cancelled`, the attempt ends `CANCELED`, not `FAILED`. Test owner: Task 4.

```python
class Pattern(StrEnum): CO_LOCATION = "CO_LOCATION"; CONFLICT = "CONFLICT"

@dataclass(frozen=True)
class Sighting:
    evidence_id: str; observation_id: str; subject: str   # resolved PERSON/ASSET id
    cell: tuple[int, int]; location: str                  # (col, row), LOC-GRID-nn
    start: datetime; end: datetime

@dataclass(frozen=True)
class PlacementCandidate:
    location: str; cell: tuple[int, int]
    sightings: tuple[Sighting, ...]        # sorted (subject, start, observation_id)
    patterns: frozenset[Pattern]
    @property
    def about(self) -> list[str]: ...      # sorted({s.subject}) + [location]
    @property
    def evidence_ids(self) -> list[str]: ...  # sorted unique
    valid_from / valid_until properties    # min start / max end

@dataclass(frozen=True)
class Resolution:
    sightings: list[Sighting]; unresolved: int; off_grid: int

def resolve_sightings(manifest: ScenarioManifest, logs: Mapping[str, SightingLog]) -> Resolution: ...
def placement_candidates(manifest: ScenarioManifest, sightings: Sequence[Sighting]) -> list[PlacementCandidate]: ...
    # sorted by (location, valid_from)
```

**The rules that the signatures don't settle:**
- **Resolving a subject:** `manifest.alias_index()`. Keep the subject only if `manifest.entity(id).type` is PERSON or ASSET.
- **Mapping a point to a place:** `grid.cell_of(x, y)` gives the cell; `manifest.location_at_cell(col, row)` gives the LOC id. If either returns `None`, the point counts as off-grid.
- **Distance:** the Euclidean distance between the two cell centres.
- **Overlap:** windows are half-open, so they overlap when `a.start < b.end and b.start < a.end`.
- **Edges:**
  - co-location: different subjects at distance `<= grid.neighbour_radius`, windows overlapping;
  - conflict: the same subject at distance `> grid.neighbour_radius`, windows overlapping.
- **Grouping:** take the connected components of the edge graph (union-find over sighting indices). Within each component, group by `cell`; each group is one candidate. A sighting with no edges produces nothing.
